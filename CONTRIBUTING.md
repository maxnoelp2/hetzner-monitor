# Contributing

Thanks for helping! This project is built by humans and AI agents together, so the process is
written down explicitly.

1. Read [ARCHITECTURE.md](ARCHITECTURE.md) and [CLAUDE.md](CLAUDE.md) (the rules apply to humans too).
2. For non-trivial work, write an execution plan in [docs/plans/](docs/plans/README.md) first.
3. Architectural decisions go into an [ADR](docs/adr/README.md).
4. Keep PRs small; use [Conventional Commits](https://www.conventionalcommits.org/).
5. Update docs in the same PR as the behaviour change.

By contributing you agree that your contributions are licensed under the [AGPL-3.0](LICENSE).

Security issues: please follow [SECURITY.md](SECURITY.md) — do not open a public issue.
